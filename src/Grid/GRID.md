Make sure to review .claude/skills/webflow-code-components if you need docs and property details. 

# Grid Features

## Properties 

- Settings
    - Columns [number]  min 1, max 100 
- Content
    - Content [slot]
- Advanced
    - Debug Mode [boolean] on / off default off 

## Behavior

- Finds the slot 
- Changes the slot to a CSS grid layout of N columns
