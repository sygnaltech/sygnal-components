# Sygnal Components

**Sygnal Components is a library of reusable UI components built for Webflow.** Each component integrates directly into the Webflow Designer, with configurable properties, slots, and variants — no code required.

## What's Included

11 components across layout, media, navigation, utility, and interactive categories:

| Component | Group | Description |
|-----------|-------|-------------|
| [Code Embed](/sygnal-components/code-embed) | Utility | Embed external HTML/CSS/JS from a CDN via iframe |
| [Color Swatch](/sygnal-components/color-swatch) | UI | Clickable color swatch with clipboard copy and contrast-aware labels |
| [Countdown Timer](/sygnal-components/countdown-timer) | Utility | Persistent countdown that survives page reloads |
| [CSS Isolator](/sygnal-components/css-isolator) | Style | Scope CSS variables and rules to a container |
| [Dropdown](/sygnal-components/dropdown) | Navigation | Nestable dropdown menu with hover or click triggers |
| [Grid](/sygnal-components/grid) | Layout | CSS grid with configurable column count |
| [IFrame](/sygnal-components/iframe) | Utility | Embed external URLs with sandbox and permission controls |
| [QR Code](/sygnal-components/qr-code) | Media | Generate QR codes from any text or URL |
| [Script Manager](/sygnal-components/script-manager) | Utility | Load different scripts per environment (dev/test/prod) |
| [SVG Icon](/sygnal-components/svg-icon) | Media | Render inline SVG code with validation |
| [VCard](/sygnal-components/vcard) | Interactive | Download contact info as a `.vcf` file |

## How It Works

Components are added to your Webflow project as code components. Once installed, they appear in the Webflow Designer's component panel. Each component exposes properties that can be configured directly in the Designer's right panel — no custom code needed on individual pages.
