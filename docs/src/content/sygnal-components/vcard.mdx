# VCard

![VCard component in Webflow Designer](/components/vcard.png)

The VCard component generates a contact card in vCard 3.0 format and triggers a browser download when activated. Share contact information directly from your site — visitors can save it to their phone or desktop contact manager in one tap.

All contact fields are CMS-bindable, making this ideal for employee directories, speaker pages, and contact listings.

**Group:** Interactive

## Best Practices

- **Full Name is required.** First Name and Last Name are also recommended as separate fields for better compatibility with contact apps.
- VCards are primarily useful on mobile. Consider hiding the component on tablet and desktop breakpoints, or placing it in a mobile-only section.

## Properties

### Display

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `variant` | Variant | `Button` | `Button` — renders a built-in download button. `Slot` — wraps custom content; clicking anywhere inside triggers the download. |
| `buttonText` | Text | `Save to Contacts` | Label text for the built-in button. Only used when `variant` is `Button`. |
| `buttonStyle` | Text | `''` | Inline CSS applied to the built-in button. Only used when `variant` is `Button`. |
| `Slot` | Slot | — | Custom clickable content. Only used when `variant` is `Slot`. |

### Download

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `filename` | Text | `contact.vcf` | The downloaded file name. `.vcf` is automatically appended if not already present. |

## Interaction Modes

### Button variant

The component renders a built-in styled button (blue background, white text, `12px 24px` padding by default). Customize appearance with the `buttonStyle` property using inline CSS:

```
background-color: #111827; color: white; border-radius: 6px; padding: 10px 20px; font-weight: 600;
```

### Slot variant

Set `variant` to `Slot` and design any Webflow element inside the slot — a button, banner, card, or link. The entire slot area becomes clickable and triggers the vCard download. This gives you full control over the trigger's appearance using Webflow's native design tools.

## Generated vCard Format

The component outputs a vCard 3.0 file. Only fields with non-empty values are included:

```
BEGIN:VCARD
VERSION:3.0
N:Smith;John;;;
FN:John Smith
ORG:Acme Corp
TITLE:Product Manager
TEL;TYPE=CELL:+1 555 000 0001
TEL;TYPE=WORK,VOICE:+1 555 000 0002
EMAIL;TYPE=WORK:john@acme.com
EMAIL:john@personal.com
ADR;TYPE=WORK:;;123 Main St;Springfield;IL;62701;USA
URL:https://john.example.com
NOTE:Met at conference 2024
END:VCARD
```

### vCard Field Mapping

| Property | vCard Field | Type Tag |
|----------|-------------|---------|
| `firstName` + `lastName` | `N` | — |
| `fullName` | `FN` | — |
| `organization` | `ORG` | — |
| `title` | `TITLE` | — |
| `cellPhone` | `TEL` | `CELL` |
| `workPhone` | `TEL` | `WORK,VOICE` |
| `email` | `EMAIL` | `WORK` |
| `additionalEmail` | `EMAIL` | — |
| `streetAddress` + `city` + `state` + `postalCode` + `country` | `ADR` | `WORK` |
| `websiteUrl` | `URL` | — |
| `note` | `NOTE` | — |

## Download Behavior

The component creates a `Blob` with the vCard content and type `text/vcard`, generates a temporary object URL, triggers the browser download dialog, then immediately revokes the URL. No server-side processing is required.

## CMS Binding

Bind any contact field to a CMS field for dynamic contact pages. Useful patterns:

- Employee directory: bind all fields to a Staff CMS collection
- Speaker listing: bind name, title, organization, and email
- Contact page: use a single-item CMS collection as a data source
