# Sygnal Components

General-purpose code components to support your Webflow designs. All components integrate directly into the Webflow Designer with configurable properties, slots, and variants.

## Components

| Component | Description |
|-----------|-------------|
| [Code Embed](/sygnal-components/code-embed) | Embed external HTML/CSS/JS from a CDN via iframe |
| [Color Swatch](/sygnal-components/color-swatch) | Clickable color swatch with clipboard copy and contrast-aware labels |
| [Countdown Timer](/sygnal-components/countdown-timer) | Persistent countdown that survives page reloads |
| [CSS Isolator](/sygnal-components/css-isolator) | Scope CSS variables and rules to a container |
| [Dropdown](/sygnal-components/dropdown) | Nestable dropdown menu with hover or click triggers |
| [Grid](/sygnal-components/grid) | CSS grid with configurable column count |
| [IFrame](/sygnal-components/iframe) | Embed external URLs with sandbox and permission controls |
| [QR Code](/sygnal-components/qr-code) | Generate QR codes from any text or URL |
| [Script Manager](/sygnal-components/script-manager) | Load different scripts per environment (dev/test/prod) |
| [SVG Icon](/sygnal-components/svg-icon) | Render inline SVG code with validation |
| [VCard](/sygnal-components/vcard) | Download contact info as a `.vcf` file |
