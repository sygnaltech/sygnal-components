# SVG Icon

![SVG Icon component in Webflow Designer](/components/svg-icon.png)

In standard Webflow, inline SVGs are added using an Embed element — but that approach has limitations: the SVG cannot be stored in the CMS and bound to an Embed, and it cannot be componentized and slotted conveniently. SVG Icon solves both problems.

**Group:** Media

## Features

- Paste SVG code directly into a property field
- **CMS-bindable** — store SVG markup in a plain text CMS field and bind it to the property for item-specific icons
- Choose from six preset sizes
- Color the icon through its wrapper div using the SVG `currentColor` property — that color can be stored in the CMS as a color field and bound to the wrapper's text color
- Automatically validates that the input is valid SVG before rendering

## Properties

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `svg` | Text | — | SVG markup string (the full `<svg>...</svg>` element). |
| `variant` | Variant | `16x16` | Preset output dimensions applied to the rendered SVG container. |

## Size Options

| Variant | Dimensions |
|---------|-----------|
| `16x16` | 16 × 16 px |
| `24x24` | 24 × 24 px |
| `32x32` | 32 × 32 px |
| `48x48` | 48 × 48 px |
| `80x80` | 80 × 80 px |
| `104x104` | 104 × 104 px |

Sizes are fixed pixel dimensions. The component wrapper is sized to the variant and the SVG renders within it.

## Providing SVG Markup

Paste the full `<svg>` element into the `svg` property. The SVG must be valid XML. If the markup fails validation, the component renders an error state rather than broken HTML.

```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2">
  <circle cx="12" cy="12" r="10"/>
  <line x1="12" y1="8" x2="12" y2="12"/>
  <line x1="12" y1="16" x2="12.01" y2="16"/>
</svg>
```

## CMS Binding

Store SVG markup in a plain text CMS field. When the SVG Icon is inside a Collection List, bind the `svg` property to the CMS text field. This lets each CMS item have its own icon without any custom code.

## Controlling Color

Use `currentColor` in your SVG's `stroke` or `fill` attributes. The icon then inherits its color from the parent element's CSS `color` property — set this in Webflow's style panel on the component wrapper.

```xml
<!-- Icon inherits color from parent element's text color -->
<svg ... stroke="currentColor" fill="none">...</svg>
```

You can also bind the wrapper's text color to a CMS color field for per-item icon colors.

## HTML Entity Decoding

When entering SVG markup in Webflow's Designer text fields, certain characters may be encoded as HTML entities (`&lt;`, `&amp;`, `&quot;`). The component automatically decodes these before rendering, so SVG copied from tools like Figma or Illustrator renders correctly without manual cleanup.

## Default Icon

If the `svg` property is empty, the component renders a default plus/cross icon as a placeholder, making the component easy to identify and configure in the Designer.

## Validation

The SVG string is parsed with `DOMParser` before rendering. If the parsed document contains a `parsererror` element, the SVG is considered invalid and an error state is shown instead.

## Use Cases

- UI icons from icon libraries (Lucide, Heroicons, Feather, etc.)
- CMS-driven icons where different items need different icons
- Brand logos stored and managed in the CMS
- Inline diagrams or illustrations that need to scale without pixelation
