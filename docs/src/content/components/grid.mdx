# Grid

![Grid component in Webflow Designer](/components/grid.png)

The Grid component distributes slotted content across a configurable number of equal-width columns using CSS grid. It uses `minmax(0, 1fr)` columns so items shrink correctly even when their content would otherwise overflow.

**Group:** Layout

## Purpose

This component exists to satisfy Webflow's slot restrictions — only components can be slotted within other components. A typical construction is:

- A **Section** component with a large content slot
- Containing a **Grid** component
- Which has the content cards slotted inside it

## Properties

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `columns` | Number | `3` | Number of equal-width columns. Accepted range: 1–100. |
| `content` | Slot | — | Items to distribute across the grid columns. |
| `debugMode` | Boolean | `false` | Shows a debug panel indicating the active column count. |

## Column Layout

The grid is defined as:

```css
grid-template-columns: repeat(N, minmax(0, 1fr));
gap: 1rem;
```

Where `N` is the `columns` value. All columns are equal width and flex with the container.

Slotted child elements receive `display: contents`, which removes them from the layout box model so their children participate directly in the grid. This lets you nest Webflow elements inside the slot without creating an extra wrapper that breaks the grid structure.

**Note:** Columns are fixed `1fr` — there is currently no feature for variable column sizes.

## Responsive Layouts

The Grid component sets a fixed column count. For responsive behavior:

- Use multiple Grid components with Webflow's conditional visibility, each with a different `columns` value suited to that breakpoint
- Or wrap the Grid in a parent element and use Webflow's custom CSS to control when it switches to a single column

## Gap

The gap between grid items is fixed at `1rem`. To adjust, apply custom CSS to the Grid's wrapper element.

## Debug Mode

Enable `debugMode` to show a panel spanning all grid columns that displays the current `columns` value. Useful for confirming configuration while building. Disable before publishing.
