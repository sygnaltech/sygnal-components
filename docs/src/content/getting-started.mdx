# Getting Started

Sygnal Components are installed into your Webflow workspace through **Sygnal Studio**. Once installed, all components appear in the Webflow Designer and can be added to any site in that workspace.

## Requirements

To use Sygnal's components you must have; 

- A Webflow site with a **Paid Site Plan**, or a site in a **Paid Workspace**
- You must be the **owner** of the workspace to generate the required API token
  - If you are an agency or freelancer guest, the workspace owner must generate the token for you

## Step 1: Log in to Sygnal Studio

Visit [studio.sygnal.com](https://studio.sygnal.com) and sign in with a Google account.

## Step 2: Add Your Workspace

On the main screen, click **Add Workspace**. You'll see the Add Workspace form:

![Add Workspace form in Sygnal Studio](/components/install-add-workspace.png)

## Step 3: Generate a Webflow API Token

> Open a new browser tab for this step (`Ctrl+N` / `Cmd+N`) so the Add Workspace form stays open and ready.

1. Visit your [Webflow dashboard](https://webflow.com/dashboard).
2. In the left menu under **Settings**, expand **Apps & Integrations** and click **Manage**.

![Webflow Apps & Integrations settings](/components/install-apps-integrations.png)

3. Scroll to the bottom of the page to the **Workspace API access** section.
4. Click the blue **Generate API token** button.

![Generate API token button](/components/install-generate-token.png)

5. Enter the token settings:
   - **Name:** `Sygnal Studio` (for easy identification)
   - **Code components** permissions: set to **Read and write**
6. Click **Generate token**.

![API token settings form](/components/install-token-settings.png)

## Step 4: Save the Token in Sygnal Studio

1. Copy the generated API token.
2. Return to the Sygnal Studio tab.
3. Paste the token into the **Webflow API Token** field in the Add Workspace form.
4. Click **Add Workspace**.
5. Once saved, return to Webflow and click **Hide token forever**.

![Hide token button in Webflow](/components/install-hide-token.png)

Your workspace is now connected. You'll see it listed in Sygnal Studio.

![Saved token in Webflow](/components/install-token-saved.png)

## Step 5: Install the Component Library

From Sygnal Studio, select the **Sygnal Components** library and install it into your workspace. The library is deployed workspace-wide — all sites in the workspace gain access to the components immediately.

## Using Components in the Designer

1. Open any site in the Webflow Designer.
2. Click the **Components** panel icon in the left sidebar.
3. Find the components under the **Sygnal** group.
4. Drag a component onto the canvas.
5. Select it on the canvas to open its property panel on the right.
6. Configure properties — text, numbers, variants, and toggles.

## Working with Slots

Many components include **Slot** properties. Slots let you place your own Webflow elements inside the component, which the component then positions or activates with its logic.

To add content to a slot:
1. Select the component on the canvas.
2. Double-click into the slot area.
3. Add and style child elements normally.

## Multiple Workspaces

If you have multiple Webflow workspaces, register each one separately in Sygnal Studio using **Add Workspace**. Each workspace requires its own API token.

## Important Notes

- If you make a mistake and hide the token before saving it in Sygnal Studio, simply revoke that token in Webflow and repeat the process.
- Sygnal Studio encrypts your API key before storing it.
- The workspace owner must perform the API token step. If sharing the key with a team member, use a secure communication channel.

## Development Notes

If you are building or customizing the library itself:

- `npm run dev` — Start the Vite development server
- `npm run build` — Build for production
- `npm run deploy` — Deploy components to the Webflow library

See `CLAUDE.md` in the repository root for full development commands and architecture details.
